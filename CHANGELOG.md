# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-08-23
### Added
- Monthly transaction calendar in the Transactions > Summary view.
- Daily income/expense totals per calendar day with today and selected-day states.
- Day detail bottom sheet showing transactions grouped by type plus net result.

## [1.0.2] - 2026-06-29
### Added
- JSON export/import for data backup and restore.
- Manual backup and restore functionality in Sync tab.
- New "Sync" tab in the bottom navigation bar.

## [1.0.0] - 2026-06-28
### Added
- Initial release.
- Income and expense tracking with daily breakdowns.
- Subscription management with monthly payment tracking and installment support.
- Category-based spending visualization with charts.
- PWA support for offline use.
